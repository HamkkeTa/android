# 함께타 UI 프로토타입

현재 브랜치: `feature/carpool-dashboard-settlement`

## 화면 흐름

- **그룹**: 처음에는 운행을 시작한 그룹이 없습니다. 카드 본문은 오른쪽 멤버 보기, `자동 시작`은 운행 상태 시작, 별도의 `분담 규칙`은 해당 그룹의 설정 화면입니다. 첫 그룹은 선택 전에도 멤버 미리보기에 표시될 수 있습니다.
- **자동 시작**: 한 번에 한 그룹만 시작할 수 있습니다. `취소하기` 전까지 그 그룹의 동승자 등록·삭제와 규칙 저장을 UI와 ViewModel 양쪽에서 차단합니다. 상태는 SavedStateHandle로 화면 재생성 시 복원합니다. 실제 주행·자동 비용 계산은 수행하지 않습니다.
- **동승자 등록**: `블루투스 연결하기` → 별도 등록 화면 → 예시 기기 선택, 이름·전화번호 입력, 필수 동의 두 항목 선택 → `등록하기` → 원래 그룹 화면으로 돌아옵니다. 기기 목록은 UI용 예시로 실제 검색/페어링 결과가 아닙니다.
- **새 그룹**: 새 그룹 버튼을 누르면 오른쪽 패널이 이름·멤버 작성 모드로 바뀝니다. 등록 화면을 왕복하면서 멤버를 더한 뒤 `그룹 만들기`를 누르면 로컬에 저장됩니다. 기본 규칙은 운전자 포함, 면제 없음, 유류비·통행료·주차비 모두 포함입니다.
- **분담 규칙**: 운전자 포함/동승자만 중 선택하고, 면제 동승자를 각각 선택·해제할 수 있습니다. 비용 항목은 포함/제외, 삭제, 사용자 항목 추가, 기본 항목 복원을 지원합니다. 저장/취소를 분리하며 설정은 그룹별 로컬 저장입니다. 이 화면의 금액은 고정된 UI 예시로 자동 정산 엔진에 연결하지 않았습니다.
- **장부**: 그룹별 11월 예시 5회 운행, 누적 100km, 동승자 합계 8,250원을 표시합니다. 표의 행을 누르면 선택한 그룹·날짜의 운행 요약으로 이동합니다. 월말 자동 발송 토글은 UI 상태만 변경합니다.
- **운행 요약**: 예시 탑승 구간과 개인별 금액을 표시합니다. `장부에 모으기`는 해당 예시 행의 상태를 바꾸며 중복 저장을 막습니다. `카톡으로 내보내기`는 안내만 표시하며 실제 메시지를 전송하지 않습니다.

## 예시 데이터와 실제 데이터

처음 실행하면 참고 이미지와 같은 출근·퇴근·동호회 예시 그룹을 제공합니다. 기존 로컬 그룹은 덮어쓰지 않습니다. 이전 데이터에 없는 비용/기기 이름 필드는 로딩 시 기본값을 보완합니다.

그룹·등록 동승자·분담 규칙·비용 항목은 로컬 SharedPreferences에 저장됩니다. 예시 장부는 고정 fixture로 실제 차량 기록과 분리되어 있습니다. 장부의 날짜·거리·금액과 상세 화면의 금액은 같은 fixture에서 가져옵니다. 장부의 동승자 합계는 운전자 부담액을 제외합니다.

BLE GATT 기반 탑승 저장소와 하차 유예 코드는 유지합니다. 멤버 미리보기는 BLE 활성 그룹을 바꾸지 않고 `자동 시작`할 때만 해당 그룹을 연결합니다. UI에서 선택한 예시 휴대폰 이름은 실제 BLE 기기 인증이나 페어링을 의미하지 않습니다. 실제 동승자 앱의 연결 ID 쓰기 프로토콜과 기기 인증은 별도 연동이 필요합니다.

차량 속도·시동·좌석·도어 센서, 실측 거리·연비·유가·통행료, 실제 월말 청구 및 카카오톡 발송은 미연동입니다. UI 잠금은 차량 속도 기반 안전 잠금을 대체하지 않습니다.

## 검증

```powershell
.\gradlew.bat :app:ktlintFormat
.\gradlew.bat :app:ktlintCheck :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
.\gradlew.bat :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=com.example.hamkketa.carpool.CarpoolFlowTest'
```

`CarpoolFlowTest`는 테스트 전용 SharedPreferences를 사용하여 실제 앱 데이터와 분리합니다. 운행 중 편집 차단, 시작/종료와 BLE 그룹 연결, 초안 왕복과 새 그룹 기본값, 그룹별 비용·면제 설정 저장, 이전 데이터 호환을 검증합니다.
