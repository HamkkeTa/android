# feat: 탑승 구간별 주행거리 정산과 에뮬레이터 검증 구현

## 목적

그룹에서 자동 시작을 누르면 운행을 기록하고, 취소하기로 종료하면 실제 탑승 구간에 따라 동승자별 부담액을 계산해 장부에 보관한다.

## 작업 내용

- 연비·휘발유 단가 직접 입력 및 운행 시작 시 그룹·분담 규칙·단가 고정
- Pleos Vehicle SDK 거리·도어 연동과 별도의 에뮬레이터 수동 이벤트 입력
- BLE 연결·RSSI·도어 개폐로 탑승 판정, 연결 해제 유예 및 재연결 처리
- 하차 확정 시 최초 연결 해제 거리로 구간 종료
- 운전자 포함/제외, 동승자 면제, 비용 항목 선택 및 10원 단위 차액 배분
- 실제 운행 요약·그룹별 장부·주/월 누적 및 정산 요청 내용 복사
- 개발용 동승자 BLE 테스트 앱과 중간 탑승·하차·재연결·복구 테스트
- 주행 제한 상태에서 조작 화면을 숨기고 탑승 현황 아이콘 표시

## 제약

- 현재 테스트 대상은 Pleos 에뮬레이터이며, 연비·단가는 직접 입력한다.
- 좌석을 동승자에게 지정하지 않으므로 착석 센서 조건은 제외한다.
- 하차 유예 30초, 탑승 RSSI -65 dBm, 도어 개폐 유효 시간 60초는 파일럿용 기본값이다.
- 통행료·주차비·사용자 비용은 수동 입력하며 외부 유가/통행료 API는 연결하지 않는다.
- 실제 서비스의 목표는 동승자 앱 설치 없음이다. 현재 BLE GATT 검증에는 별도 테스트 앱이 필요하며, 일반 폰 페어링만으로 앱 없는 다중 동승자 감지를 지원한다고 간주하지 않는다. 차량의 표준 블루투스 연결 이벤트 제공 여부를 추가 확인해야 한다.
- 카카오톡 자동 발송은 미연동이며, 현재 정산 요청 텍스트를 복사해 직접 전달한다. 앱 내 결제나 송금은 제공하지 않는다.
- 거리 누락·프로세스 중단 기록은 정산 보류로 표시하며 누적 청구에서 제외한다.

## 검증 기준

- 20 km, 12 km/L, 1,650원/L, B 처음부터/C 8 km부터 탑승 시 운전자 1,100원/B 1,100원/C 550원
- 중간 하차한 사람에게 이후 거리 비용을 배분하지 않음
- 유예 시간 안 재연결은 동일 탑승 유지
- 각자 금액은 10원 단위이며 합계는 전체 비용의 10원 반올림 결과와 일치
- 예시 장부와 실제 기록을 섞지 않음
